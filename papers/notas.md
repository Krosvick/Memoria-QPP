1. from_ad_hoc_to_conversational: Configuración de evaluación y metodos
2. humans_cant_predict: Humanos tienen dificultades para predecir el rendimiento de las consultas - lo que significa que es una tarea no trivial
3. qppcorrelationfails: La correlación lineal (Pearson) no es una buena medida de la relevancia de las consultas - autor recomienda RMSE. Alternativamente se menciona que el rendimiento de los metodos se relaciona a la calidad del corpus.
4. queryvstopic: definición de consulta vs tópico
5. The Sixth Text REtrieval Conference: NIST experts where asked to predict the performance of the queries - max pearson correlation was 0.26
6. microsoftpreretrieval: Modern evaluation made by microsoft researchers
7. SMV-2014: se presenta SMV, ademas se define configuración para WIG
8. smare_and_definitions: Se define el paradigma sMARE de evaluación y se definen metodos
9. query-drift-nqc: presentación de NQC,y su configuración
10. definition_of_query_difficulty: Evaluación utilizando clasificación, se proponen definiciones sobre "dificultad de consulta"
11. qpptk-benchmark: Benchmark de metodos QPP clasicos en tirex
12. qppframeworkUEF: Modificación de metodos post retrieval para mejorar su rendimiento
13. RSD-2017: Se presenta RSD, un metodo basado en desviación estandar robusta - metodo mas novel
14. Query Performance Prediction Through Retrieval Coherency(https://sci-hub.se/https://doi.org/10.1007/978-3-030-72240-1_15): Presenta un metodo novel para predecir el rendimiento de las consultas utilizando la coherencia de la recuperación. followup de RSD
